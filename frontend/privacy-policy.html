Privacy Policy

Last updated: December 2, 2025

1. Data Collection

This application uses Google Gmail API to send and manage emails. We only access email data necessary for the application's functionality.

We collect and process the following information:

  • Email addresses for sending campaigns
  • Email content for processing replies
  • Campaign metadata (status, send dates, etc.)

2. Data Usage

Email data is used solely for:

  • Sending emails through the application
  • Processing email replies and forwarding
  • Managing email campaigns
  • Tracking campaign statistics

We do not use your data for advertising or share it with third parties.

3. Data Storage

We store minimal data necessary for application functionality:

  • Campaign metadata is stored in our database
  • Email content is processed through Google's Gmail API and not stored on our servers
  • OAuth tokens are securely stored in environment variables

4. OAuth Permissions

This application requires the following Gmail API permissions:

  • gmail.readonly - Read-only access to emails for processing replies
  • gmail.modify - Modify emails (mark as read) for managing processed emails

These permissions are requested through Google OAuth 2.0 and can be revoked at any time through your Google Account settings.

5. Data Security

We implement security measures to protect your data:

  • All API communications use HTTPS encryption
  • OAuth tokens are stored securely and never exposed
  • Access to the application is restricted to authorized users

6. Your Rights

You have the right to:

  • Revoke OAuth access at any time through Google Account settings
  • Request deletion of your campaign data
  • Access your stored data

7. Contact

For questions about this privacy policy or to exercise your rights, please contact:
