# Создание Demo Video для Google OAuth

## Проблема
Google требует обязательное demo video для публикации OAuth приложения с Gmail scopes.

## Решение: Создать простое видео

### Вариант 1: Записать экран (рекомендуется)

1. **Используйте встроенные инструменты:**
   - **Mac**: QuickTime Player → File → New Screen Recording
   - **Windows**: Win + G (Game Bar) → Record
   - **Linux**: OBS Studio или SimpleScreenRecorder

2. **Запишите 2-3 минуты:**
   - Покажите интерфейс приложения (если есть)
   - Покажите процесс отправки email
   - Покажите получение reply
   - Покажите обработку reply

3. **Сохраните видео** (MP4 формат)

4. **Загрузите на YouTube:**
   - Создайте аккаунт YouTube (если нет)
   - Загрузите видео
   - Сделайте его **Unlisted** (не публичным)
   - Скопируйте ссылку

5. **Вставьте ссылку в Google Cloud Console**

### Вариант 2: Создать видео из скриншотов (быстрее)

1. **Сделайте скриншоты:**
   - Главная страница приложения
   - Интерфейс отправки email
   - Пример отправленного email
   - Пример полученного reply

2. **Создайте видео из скриншотов:**
   - Используйте онлайн-сервис: https://www.freeconvert.com/jpg-to-mp4
   - Или используйте FFmpeg (если установлен)

3. **Загрузите на YouTube** (как в варианте 1)

### Вариант 3: Минимальное видео (самый быстрый способ)

1. **Создайте простой слайд-шоу:**
   - Слайд 1: Название приложения "Gmail Sender App"
   - Слайд 2: Описание "Email Campaign Management System"
   - Слайд 3: Скриншот интерфейса (если есть)
   - Слайд 4: Пример использования

2. **Используйте онлайн-сервис:**
   - https://www.animoto.com/ (бесплатный план)
   - https://www.canva.com/ (создание видео)
   - Или любой другой видеоредактор

3. **Экспортируйте в MP4** (минимум 30 секунд)

4. **Загрузите на YouTube** (Unlisted)

### Быстрый способ с FFmpeg (если установлен)

```bash
# Создать видео из скриншотов (если есть скриншоты)
ffmpeg -framerate 1/2 -pattern_type glob -i 'screenshots/*.png' -c:v libx264 -pix_fmt yuv420p demo.mp4
```

### Минимальные требования к видео

- **Длительность**: минимум 30 секунд (рекомендуется 1-2 минуты)
- **Формат**: MP4
- **Размер**: до 100MB (обычно достаточно)
- **Содержание**: должно показывать использование Gmail API scopes

### Что показать в видео

1. **Вступление** (5-10 сек):
   - Название приложения
   - Краткое описание

2. **Основная часть** (1-2 минуты):
   - Покажите интерфейс приложения
   - Покажите процесс отправки email кампании
   - Покажите получение reply
   - Покажите обработку reply

3. **Заключение** (5-10 сек):
   - Краткое резюме функциональности

### Если нет интерфейса

Если у вас нет веб-интерфейса, покажите:
- Скриншот логов работы приложения
- Пример отправленного email
- Пример полученного reply
- Описание workflow в текстовом виде

### Альтернатива: Использовать существующее видео

Если у вас уже есть демонстрация работы приложения, можно использовать её.

## После создания видео

1. Загрузите на YouTube (Unlisted)
2. Скопируйте ссылку
3. Вставьте в Google Cloud Console в поле "Demo Video"
4. Кнопка SAVE станет активной
